- Identified a **generalization gap** between agents optimized for retrieval-based question answering and those optimized for long-horizon deep search: deep-search agents underperform on conventional search benchmarks.
- Exploring **unified search agent** frameworks that jointly learn from general-search and deep-search trajectories with supervised learning and RL-based policy optimization, balancing efficient retrieval with long-horizon exploration.
- Built a controlled evaluation framework across **PopQA, 2WikiMultiHopQA, BrowseComp, and BrowseComp-ZH** to measure cross-regime generalization and compare tool-use and search behaviors.
